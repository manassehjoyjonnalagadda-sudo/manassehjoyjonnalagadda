# Manasseh Joy — Badminton Coaching & Performance Website

A responsive static portfolio with a playable video gallery. It uses HTML, CSS and JavaScript and can be hosted on GitHub Pages for free.

## Website files
- `index.html` — page content and video gallery
- `styles.css` — layout and responsive styling
- `script.js` — mobile navigation and coaching field-note interactions
- `videos/clip-01.mp4` through `videos/clip-20.mp4` — compressed web versions of the supplied clips

## Publish/update on GitHub Pages from a phone
1. Download and extract the ZIP on a computer, or use a file manager that can open ZIP files.
2. In the GitHub repository, upload/replace `index.html`, `styles.css`, and `script.js`.
3. Upload the entire `videos` folder with all 20 MP4 files. Keep the folder name exactly `videos` and filenames unchanged.
4. Commit the changes to the `main` branch. GitHub Pages will redeploy automatically.
5. Open the live site and test several videos on mobile data/Wi-Fi.

If GitHub's mobile interface does not allow uploading a folder, create the `videos` folder in the repository first, then upload the MP4 files into it, or use GitHub Desktop on a computer. Do not upload the original large clips if using the compressed versions here.

## Notes
- The videos have generic numbered titles because the clips have not all been individually reviewed for content. Edit the titles and descriptions in `index.html` once you decide what each clip demonstrates.
- Before publishing footage of athletes, especially minors, ensure you have permission to share it publicly.
- Replace generic stock imagery and verify all professional claims, dates, qualifications and links before sending the website to recruiters.
