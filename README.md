# Jonnalagadda Manasseh Joy — Personal Coaching Website

A responsive static portfolio website for badminton coaching, athlete development, achievements, certificates and professional contact.

## Contents
- `index.html`, `styles.css`, `script.js`
- `images/`: exactly 10 supplied photos (8 general portfolio photos and 2 international-player photos)
- `certificates/`: 7 certificate PDFs

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Wait for GitHub Pages to finish deploying.

## Before sharing widely
- Check all CV details and certificate titles against your original documents.
- Confirm permission to publish photos showing students and other people.
- Add your LinkedIn URL and a public CV PDF if you want those links on the site.
- The site uses one remote Unsplash image for a decorative hero visual; the portfolio gallery itself uses only the 10 photos you supplied.

The site is static and does not require a paid backend.
