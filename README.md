# Manasseh Joy — Official Website

A responsive, static personal website for a badminton coach/player. Built with HTML, CSS and vanilla JavaScript; no framework, database, server or paid subscription required to host the static site.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive styling
- `script.js` — mobile navigation and interactive coaching field notes

## Before publishing (important)
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Update the LinkedIn link and add your actual resume PDF. Change the resume link to the uploaded file name (for example `Manasseh-Joy-CV.pdf`).
3. Verify all experience dates, academy names, certifications and achievements. The current experience section deliberately marks details that need confirmation; do not publish placeholders as facts.
4. Replace the sample hero image with your own approved badminton photo when ready. The current image is loaded from Unsplash and requires internet access.
5. Add real match photos, coaching-session photos, player outcomes (with consent), and links to published analysis as they become available.

## Free hosting options
### GitHub Pages
1. Create/sign into a GitHub account.
2. Create a **public** repository named `YOUR-USERNAME.github.io`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. In repository **Settings → Pages**, enable deployment from the `main` branch and root folder.
5. Your default site will be at `https://YOUR-USERNAME.github.io/`.
6. A custom domain can be connected later, but the domain itself usually costs money to register.

Official guide: https://docs.github.com/en/pages/quickstart

### Cloudflare Pages
You can also deploy this static site using Cloudflare Pages. Follow its current official setup guide: https://developers.cloudflare.com/pages/

## Domain note
A free hosting address can be used first. A personal domain such as `manassehjoy.com` is only an idea, not a confirmed available domain; availability and registration price must be checked with a domain registrar before purchasing.

## Editing
Open `index.html` in a text editor to change text and links. Open `styles.css` to adjust colors/layout. No build step is required.
